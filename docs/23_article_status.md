## Current Correct Direction

The article must now follow this logic:

- literature supports several methodological principles
- from those principles, a QA methodology is defined
- the methodology is operationalized in an empirical case
- the case produces metrics and defect evidence
- the evidence is used to evaluate the methodology

Not this logic:

- we had a project
- we implemented tests
- now we explain why the project/testing setup is good
